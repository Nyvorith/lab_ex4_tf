# 音频波形显示

本版将字幕条中的五格音量刻度替换为真实PCM时域波形，对应选题指南“结合音频数据生成频谱或波形显示，叠加于视频画面”的波形显示方向。

区域96×12，x528～623、y434～445；字幕字形y448～463，不额外扩展遮挡。波形细线使用低对比暖灰混色，按实际PCM的正负采样幅度绘制，32点、每12有效样点取1点，相邻点0.25ms、首末点跨度7.75ms。纵向增益按同一采样块峰值分档，限幅±4像素；每点占3像素，相邻点用单像素插值折线显示。它是抽取样点的定性时域显示，不是FFT频谱或精密电压测量。

双bank写入和帧边界发布避免画面中途更新；每帧发布一次完整采样块，帧内保持同一波形。缺样、静音、解说结束、自动轮播、预览、转场、无效画面隐藏并防止残留。持续零值采样显示平直中线，不伪造起伏。自动模式停止解说，退出后按用户开关偏好从头播放当前作品。

保留必要的fehdl存储映射和同步器综合属性。普通说明注释移除，第三方版权、许可和工具指令保留。最终固件由实际交付源码重新综合、布局布线生成；资源与时序见manifest。此版本已完成上板确认，旧版本保留回退。

验证覆盖55440像素参考、逐帧发布、帧内保持与缺样恢复、时间顺序、抽取、正负极值、小信号、零信号、单像素插值、双bank原子发布、缺样失效、亮度上限、字幕/HDMI流水线及所有隐藏条件；其余缓存、交互、字幕、介绍卡、解说联动回归见doc/verification。
